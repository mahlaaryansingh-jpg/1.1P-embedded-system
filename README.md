# 1.1P-embedded-system
This Arduino code is used to control two lights, a porch light and a hallway light, using a button. First, pin 2 is connected to the button, pin 3 to the porch light, and pin 4 to the hallway light. In the setup() function, the button is set as an input using INPUT_PULLUP, while both lights are set as outputs and turned OFF. In the loop() function, Arduino continuously checks whether the button is pressed. Because INPUT_PULLUP is used, the button gives a LOW signal when it is pressed. When the button is pressed, both the porch light and hallway light turn ON. After 2 seconds, the porch light turns OFF, while the hallway light remains ON. After another 2 seconds, the hallway light also turns OFF.
